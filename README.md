# SLOPE 2.0 — Phase 5 Complete Starter

Working MVP through Phase 5: foundation, JWT auth, career selection, baseline assessment, deterministic mastery, personalized roadmap, learning units, resources, persisted progress and learning events.

## Run
Backend:
`cd backend && npm install && cp .env.example .env` then edit `.env`, `npm run seed`, `npm run dev`

Frontend in another terminal:
`cd frontend && npm install && cp .env.example .env && npm run dev`

Frontend: http://localhost:5173
Backend: http://localhost:8000

Do not commit `.env`.
